Optional catalogue UI fonts
===========================

The PDF layout and PDF typography come from DatasheetTemplate.docx.

For the browser catalogue interface, these optional licensed font files may be
stored directly in WEB_FOLDER_ID:

- EmbracoBeauSans-Thin.otf
- EmbracoBeauSans-Regular.otf
- EmbracoBeauSans-Bold.otf

They are not included in this package.
